# Planmoy Complete Source Export

This archive contains the Planmoy source project, web assets, Capacitor Android project, Capacitor iOS project, server code, migrations, and project documentation.

Excluded intentionally:
- `.env` and other secret-bearing environment files
- `node_modules/`
- `.git/`
- build caches and temporary files

Build targets:
- Web: `bun run build`, output `dist/`
- Android source: `android/`
- iOS source: `ios/`

The archive is source code, not signed APK/AAB/IPA binaries.
